# How to work: build your own examples first

Before answering any question, spend your first few minutes making examples for *this* schema:

1. Pick three or four readings from the schema listing that look like they matter — a count, a
   join across two types, a filter on a value, a grouped total.
2. Write one small query for each, run it with `./try`, and keep the ones that work in a file
   of your own. You now have worked examples in this schema's own vocabulary, which the primer
   cannot give you because the primer does not know this schema.
3. Answer the questions by finding the example closest in shape to each one and adapting it.
4. When a question has no close example, write a new small one first, get it working, and add
   it to your file.

The point of the method is that the examples are in the schema you are actually being asked
about, so adapting one is more reliable than writing from the primer each time.
